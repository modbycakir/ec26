# ec26
Pes 21 / FL 26 GamePlay Mod 
1. Copy the ec26.lua, Ec26_Profiles.ini, and Ec26_Settings.ini files into your "modules" folder.
2. Add the line lua.module = "ec26.lua" to your sider.ini file.

My recommendation is to place this line as high up in the list as possible. 
If you are also using the ec26Tempo.lua module, add both modules right next to each other (one right below the other). 
I have included the ec26Tempo.lua module as an optional add-on. You can use it if you wish.

lua.module = "ec26Tempo.lua"
lua.module = "ec26.lua"
